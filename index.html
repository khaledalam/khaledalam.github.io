PHP RFC: Allow Object Property Writes on Objects Referenced by Constants

PHP 8.6Merged into php-src

TLDRAn RFC I authored and implemented: CONFIG->debug = true; is now legal for global and class constants. A constant's binding stays immutable, but the object it holds was always mutable. The vote passed 17–2 and it ships in PHP 8.6.
